### طبقة البيانات (Data Layer)

#### جدول `shoot_days` (Schema)
```typescript
interface IShootDay {
  id: ShootDayID;          // "shd_xxxxx"
  scenario_id: ProjectID;
  shoot_date: string;      // "2026-06-15"
  start_time: string;      // "08:00"
  end_time: string;        // "20:00"
  status: string;          // DRAFT | SHOOTING | COMPLETED | POSTPONED | CANCELED
  notes: string;
  created_at: string;
}
```

#### الربط مع جدول `scenes`
- كل مشهد (`IScene`) يحتوي على حقل `shoot_day_id: ShootDayID | null`
- المشاهد بدون `shoot_day_id` تظهر في "بنك المشاهد" (Unscheduled)

## 🔴 نقاط الضعف الحرجة (Critical Gaps)

### 1. أجندة بدائية جداً
- **الحالة الحالية:** تقويم شهري فقط، بدون عرض أسبوعي أو يومي أو سنوي.
- **لا يوجد:** خط زمني (Gantt Chart)، عرض أسبوعي بالساعات، عرض يومي مفصل.
- **التأثير:** لا يمكن لمدير الإنتاج رؤية كثافة التصوير عبر الأسابيع أو التخطيط طويل الأمد.

### 2. نموذج بيانات فقير
- `IShootDay` يحتوي فقط على: تاريخ، وقت بداية/نهاية، ملاحظات.
- **مفقود:** عنوان اليوم، الموقع الرئيسي، المخرج المسؤول، حالة الطقس المتوقعة، نوع اليوم (تصوير/بروفة/مونتاج)، تكلفة اليوم، ربط بفريق العمل.

### 3. لا يوجد نظام مراحل الإنتاج (Production Phases)
- لا تمييز بين: مرحلة ما قبل الإنتاج (Pre-Production)، التصوير (Production)، ما بعد الإنتاج (Post-Production).
- لا يوجد مفهوم "الأسبوع الإنتاجي" أو "المرحلة الإنتاجية".

### 4. لا يوجد Gantt Chart أو خط زمني مرئي
- أداة أساسية في كل أنظمة جدولة الإنتاج السينمائي.
- غيابها يجعل من المستحيل رؤية التداخلات الزمنية بين المشاهد والممثلين.

### 5. ملاحظات يوم التصوير غائبة عن الواجهة
- حقل `notes` موجود في قاعدة البيانات لكن `ShootDayModal` لا يعرضه ولا يسمح بتحريره.

### 6. لا تكامل مع طاقم العمل (Crew)
- لا يمكن تعيين أعضاء طاقم لأيام تصوير محددة.
- لا يوجد حساب تلقائي لتكلفة اليوم بناءً على الطاقم المعين.

### 7. الأجندة لا تدعم التفاعل
- النقر على يوم في التقويم ينشئ يوم تصوير فقط، لا يمكن الانتقال لعرض تفاصيل اليوم.
- لا يمكن سحب أيام التصوير لتغيير تواريخها مباشرة من التقويم.

## 🟡 نقاط الضعف المتوسطة (Moderate Gaps)

| النقطة | التفصيل |
|---|---|
| **لا مؤشر تقدم عام** | لا يوجد شريط يوضح نسبة المشاهد المكتملة من إجمالي المشروع |
| **لا يوجد Strip Board** | أداة أساسية في الصناعة السينمائية لعرض كل المشاهد كشرائط أفقية ملونة |
| **لا تصدير للتقويم** | لا يمكن تصدير جدول التصوير كملف `.ics` لتطبيقات التقويم |
| **لا إشعارات مسبقة** | لا تنبيه قبل يوم التصوير بـ 24/48 ساعة |
| **حساب المدة تقريبي** | يعتمد على `estimated_duration` يدوي، لا حساب ذكي |
| **لا تجميع حسب الحلقة** | في أجندة التقويم، لا تمييز لونيّ حسب الحلقة |
| **لا ملخص يومي** | عند فتح يوم من التقويم، لا يظهر ملخص شامل (Call Sheet مصغر) |
