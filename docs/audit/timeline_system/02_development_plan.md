**المشروع:** ScriptFlow Pro — Production Calendar System  
**تاريخ الإصدار:** 29 يونيو 2026  
**الهدف:** تحويل أجندة التقويم من عرض شهري بسيط إلى نظام جدولة إنتاج سينمائي احترافي متعدد الأبعاد.

## 🏗️ المرحلة 1: توسيع نموذج البيانات (Schema Evolution)

### 1.1 تطوير واجهة `IShootDay`

```diff
 interface IShootDay {
   id: ShootDayID;
   scenario_id: ProjectID;
+  title: string;                    // "يوم التقاط المشاهد الخارجية"
   shoot_date: string;
   start_time: string;
   end_time: string;
   status: string;
   notes: string;
+  day_type: DayType;               // SHOOT | REHEARSAL | TRAVEL | REST | REVIEW
+  primary_location_id: LocationID;  // الموقع الرئيسي لليوم
+  weather_forecast: string;         // الطقس المتوقع
+  call_time: string;               // وقت الحضور (يختلف عن وقت البداية)
+  wrap_time: string;               // وقت الانتهاء الفعلي
+  estimated_cost: number;           // التكلفة التقديرية لليوم
+  production_phase: ProductionPhase; // PRE_PRODUCTION | PRODUCTION | POST_PRODUCTION
+  week_number: number;              // رقم الأسبوع الإنتاجي
   created_at: string;
 }
```

### 1.2 إضافة جدول `crew_day_assignments`

```sql
CREATE TABLE crew_day_assignments (
  id TEXT PRIMARY KEY,
  shoot_day_id TEXT NOT NULL,
  crew_id TEXT NOT NULL,
  role_override TEXT,         -- إذا كان الدور مختلف عن الدور الأساسي
  call_time TEXT,             -- وقت حضور هذا العضو تحديداً
  notes TEXT,
  FOREIGN KEY (shoot_day_id) REFERENCES shoot_days(id),
  FOREIGN KEY (crew_id) REFERENCES crew(id)
);
```

### 1.3 أنواع جديدة (Enums)

```typescript
enum DayType {
  SHOOT = 'SHOOT',           // يوم تصوير
  REHEARSAL = 'REHEARSAL',   // يوم بروفة
  TRAVEL = 'TRAVEL',         // يوم تنقل
  REST = 'REST',             // يوم راحة
  REVIEW = 'REVIEW',         // يوم مراجعة (مونتاج أولي)
  SETUP = 'SETUP',           // يوم تجهيز الموقع
}

enum ProductionPhase {
  PRE_PRODUCTION = 'PRE_PRODUCTION',
  PRODUCTION = 'PRODUCTION',
  POST_PRODUCTION = 'POST_PRODUCTION',
}
```

## 🏗️ المرحلة 2: أوضاع العرض المتعددة (Multi-View Agenda)

### 2.1 العرض الشهري المحسّن (تطوير الموجود)
- تلوين الخلايا حسب نوع اليوم (DayType) بألوان مميزة
- إظهار مؤشر كثافة التصوير (شريط حراري أسفل اليوم)
- ملخص مصغر عند التمرير (Hover Tooltip) يظهر: عدد المشاهد، المواقع، الممثلين
- تلوين الأيام حسب الحلقة (Episode) إذا كان المشروع مسلسلاً
- إضافة مؤشر "يوم اليوم" (Today marker) بشريط عمودي

### 2.2 العرض الأسبوعي (جديد بالكامل)
- 7 أعمدة أفقية لكل يوم من الأسبوع
- كل عمود يعرض:
  - رأس اليوم (التاريخ، نوع اليوم، الحالة)
  - شريط زمني من وقت البداية (`call_time`) حتى `wrap_time`
  - بطاقات المشاهد مرتبة حسب الجدول الزمني داخل اليوم
  - شريط التقدم (نسبة المشاهد المكتملة)
- إمكانية سحب وإفلات المشاهد بين أيام الأسبوع
- تنقل بين الأسابيع بأزرار (السابق/التالي)
- عرض رقم الأسبوع الإنتاجي

### 2.3 العرض اليومي (جديد بالكامل)
- عرض تفصيلي ليوم تصوير واحد بنمط **Call Sheet تفاعلي**
- الأقسام:
  1. **رأس اليوم:** العنوان، التاريخ، الحالة، الطقس، أوقات الحضور والانصراف
  2. **جدول المشاهد بالترتيب الزمني:** رقم المشهد، الموقع، INT/EXT، الممثلين، المدة التقديرية
  3. **قائمة الممثلين المطلوبين:** مع أوقات حضور كل ممثل
  4. **قائمة المواقع:** مع خريطة ترتيب التنقلات
  5. **قائمة طاقم العمل المعين:** مع أدوارهم
  6. **ملاحظات المخرج:** حقل نصي حر

### 2.4 العرض السنوي (جديد بالكامل)
- تقويم حراري (Heatmap Calendar) يعرض 12 شهراً
- كل يوم يُمثل بمربع صغير ملون حسب:
  - الكثافة (عدد المشاهد = شدة اللون)
  - نوع اليوم (لون مختلف لكل نوع)
- يُستخدم للتخطيط الاستراتيجي والرؤية الشاملة لمدة المشروع
- النقر على أي يوم ينتقل مباشرة للعرض اليومي

## 🏗️ المرحلة 3: الأدوات الاحترافية (Pro Tools)

### 3.1 Gantt Chart (مخطط جانت)
- عرض أفقي لكل أيام التصوير كأشرطة زمنية
- خطوط ربط بين المشاهد المتتالية (Dependencies)
- تلوين حسب الحلقة أو الموقع أو حالة اليوم
- إمكانية تمديد/تقصير أيام التصوير بالسحب
- عرض المسار الحرج (Critical Path) للمشاهد المترابطة

### 3.2 Strip Board (لوحة الشرائط)
- عرض كلاسيكي سينمائي: كل مشهد = شريط أفقي ملون
- ألوان الشرائط:
  - أصفر: INT/DAY
  - أخضر: EXT/DAY
  - أزرق: INT/NIGHT
  - أسود: EXT/NIGHT
- إمكانية إعادة ترتيب الشرائط بالسحب لتحسين جدول التصوير
- تجميع حسب يوم التصوير مع فاصل واضح بين الأيام

### 3.3 مؤشرات الأداء الإنتاجي (KPI Dashboard)
- **نسبة الإنجاز العامة:** شريط تقدم (مشاهد مكتملة / إجمالي)
- **معدل الإنتاجية:** عدد المشاهد المكتملة يومياً (المتوسط)
- **أيام متبقية vs أيام مستهلكة**
- **التكلفة التراكمية vs الميزانية المخطط لها**
- **تحذيرات الجدول الزمني:** عدد أيام التأخير المتوقعة
- **أثقل يوم تصوير:** اليوم الذي يحتوي أكبر عدد مشاهد/ممثلين

### 3.4 نظام المعالم والمراحل (Milestones)
- إمكانية تحديد "معالم إنتاجية" على التقويم:
  - بداية التصوير
  - نهاية التصوير
  - التسليم النهائي
  - مراجعة المخرج
- تظهر كعلامات مميزة على كل أوضاع العرض
