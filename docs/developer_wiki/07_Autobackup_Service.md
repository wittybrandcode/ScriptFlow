# 🕒 خدمة النسخ الاحتياطي التلقائي (07: Autobackup Service)

يحظى أمان بيانات الكاتب والمشروع بالأولوية القصوى في `ScriptFlow`. لضمان ذلك، توجد خدمة تعمل كظِل في الخلفية لأخذ لقطات متتالية من قاعدة البيانات محلياً.

## 1. الهيكلية والمكان (Service Location)
تُدار الخدمة من خلال ملفين أساسيين:
- **`apps/desktop/src/providers/AutoBackupProvider.jsx`**: غلاف React (Context Provider) يعمل كمؤقت رئيسي في شجرة التطبيق.
- **`apps/desktop/src/services/BackupService.js`**: الطبقة المنطقية المسؤولة عن التعامل المباشر مع ملفات نظام التشغيل (OS File System).

## 2. الميكانيكية الزمنية (The Timer Logic)
يقوم الـ `AutoBackupProvider` بتشغيل حلقة لا نهائية (Interval) بمجرد فتح التطبيق وتحديد المشروع:
- **دورة النسخ (Interval Rate):** تنطلق كل **30 دقيقة**.
- **المراقبة (Lifecycle Monitoring):** يتم فحص وجود `scenarioId` ووجود اتصال سليم بقاعدة البيانات قبل إطلاق أمر النسخ، لتجنب حدوث أخطاء (Ghost backups) إذا كان المستخدم في الصفحة الرئيسية فقط (Dashboard).

## 3. طريقة عمل خدمة النسخ (How BackupService Works)
النسخ ليس عملية رفع للسحاب (Cloud)، بل هو نسخ أمني محلي مُحكم (Local Mirroring).

### خطوات تنفيذ النسخة الآمنة:
1. **تحديد المسار الفعلي (Target Path Resolution):** تعتمد الخدمة على دوال `Tauri Path` (`appDataDir` أو مسارات خاصة) لاستنتاج مكان حفظ القاعدة الحالية `scriptflow.db`.
2. **صلاحيات النطاق (Scope Permissions):** تطلب الخدمة من نظام التشغيل السماح بقراءة الملف الأساسي لضمان عدم الاصطدام بصلاحيات الـ EPERM (تُعالج من خلال `tauri.conf.json`).
3. **طباعة اللقطة (Snapshot Stamping):** يتم استنساخ الملف بالكامل وتسميته بطابع زمني (Timestamp) دقيق ليصبح بصيغة `scriptflow_backup_YYYYMMDD_HHMMSS.db`.
4. **العزل في مجلد النسخ (Isolation):** توضع النسخة في مجلد خاص بالنسخ الاحتياطية بحيث لا تختلط مع ملف التشغيل الرئيسي، وتكون جاهزة لاسترجاع المشروع (Restore) في حالة تلف أي سجلات.

## 4. الفائدة الإنتاجية والضمان (Enterprise Value)
تعتبر هذه الخدمة خط الدفاع الأخير (Last Line of Defense). في حال حدث إغلاق قهري مفاجئ لجهاز الحاسوب أثناء تفريغ الـ AutosaveQueue وتعرض ملف `scriptflow.db` للتلف، سيكون لدى الكاتب نسخة سليمة لا يتجاوز عمرها 30 دقيقة على الأكثر، وهو ما يُعد معياراً احترافياً في برامج كتابة السيناريو العملاقة.
