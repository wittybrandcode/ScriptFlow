# 🛡️ الأمان ونواة الرست والمعالجة الموازية (13: Web Workers & Rust Core)

يختتم هذا المستند التوثيق الشامل بتوضيح الطبقات الخلفية الأعمق للتطبيق: نواة لغة Rust التي تحكم الأمان، وطبقة الـ Web Workers التي توفر المعالجة الموازية الخالية من التقطيع.

## 1. طبقة المعالجة الموازية الخلفية (Web Workers Layer)
يعتمد التطبيق على الـ Web Workers لمعالجة المهام الرياضية المعقدة بعيداً عن الخيط الرئيسي (Main Thread)، مما يحافظ على استجابة واجهة المستخدم ويمنع التجمد (UI Freeze).

### أ. هيكلية العمال (Worker Architecture)
تتواجد الملفات داخل `apps/desktop/src/workers/`:
- **`WorkerFactory.js`**: مغلف ديناميكي يستخدم مكتبة **`Comlink`**. `Comlink` يزيل تعقيدات الـ `postMessage` والـ `addEventListener`، ويسمح بالاتصال بالـ Worker كما لو كان كائناً عادياً بوعود (Promises).
- **`ExportWorker.js`**: خيط المعالجة المخصص للتصدير الثقيل. يتم نقل مهام مثل قياس وحساب آلاف الصفحات لملف PDF، أو تجميع ملفات الـ `.sflow` بـ `JSZip` إلى هذا الملف ليقوم بمعالجتها بسلام.

## 2. نواة بيئة الرست المحلية (Tauri Rust Core)
`Tauri` هو الإطار الأساسي الذي يُشغل التطبيق، ومكتوب بلغة `Rust`. تقع ملفاته في `apps/desktop/src-tauri/src/`.

### أ. ملف التجميع والتهيئة (`lib.rs`)
يقوم هذا الملف بربط النواة ببعضها:
- **`get_app_root`**: دالة مكتوبة بالرست تقوم بجلب المسار الجذري للتطبيق (مثل مسار `AppData` في ويندوز أو `Documents`) لضمان حفظ قاعدة البيانات في مكان مسموح وآمن.
- **`check_db_health`**: يتم تنفيذ أمر عبر النواة لفحص وجود ملف قاعدة البيانات `scriptflow.db` والتأكد من عدم تلفه قبل إقلاع واجهة `React`.

### ب. إدارة النوافذ والحوارات (Windows & Native Dialogs)
يتولى Rust إدارة فتح نوافذ حفظ الملفات الأصلية (Native File Pickers) وتحديد نوعية الملفات المسموح بها (مثل `.sflow` أو `.pdf`). يتم ذلك بعيداً عن قيود المتصفح مما يمنح التطبيق شعوراً طبيعياً متكاملاً مع نظام التشغيل.

## 3. الأمان ونطاق الصلاحيات (Security & Scopes)
يوفر Tauri نظام أمان صارم جداً لحماية جهاز المستخدم من اختراقات الحقن النصي:

### أ. تقييد نظام الملفات (File System Scope)
من خلال مجلد `capabilities/` وملف `tauri.conf.json`، يتم تطبيق ما يسمى بـ `FS Scope`. 
- التطبيق **لا يملك** صلاحية قراءة أو كتابة أي شيء في نظام التشغيل (مثل مجلد `System32` أو `Downloads`) إلا إذا تم تعريفه صراحةً في الـ Scope.
- مُنحت الصلاحيات حصراً لمجلدات التطبيق مثل مجلد المشاريع `ScriptFlowProjects` والـ `AppLocalData`، مما يمنع خطأ `EPERM` ويحمي التطبيق في نفس الوقت.

### ب. سياسة أمن المحتوى (CSP - Content Security Policy)
تم إعداد `CSP` صارم في `tauri.conf.json` يمنع تحميل أي نصوص برمجية (Scripts) خارجية، ويقيد قراءة الصور لتكون من البروتوكولات الموثوقة فقط مثل `asset://` و `project-media://`، وهو ما يوفر جداراً منيعاً ضد هجمات `XSS`.
